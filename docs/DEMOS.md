# Great-Bevy 演示项目运行与交互手册

项目内置了针对 2D 几何粒子系统、3D DXR 光线追踪及核心 ECS 子系统的多个直观且具备交互特性的 Demonstration 示例。

---

## 1. 3D DXR 光线追踪与 DirectX 12 Ultimate 演示 (`test_demo_3d`)

### 1.1 启动方式
```powershell
cargo run --example test_demo_3d
```

### 1.2 演示特性与视觉效果
* **空间天体 PBR 材质系统**：
  * **发光恒星（Central Sun）**：高发光强度与点光源辐射。
  * **主公转行星（Metallic Planet）**：高金属度（Metallic 0.95）、极低粗糙度（PerceptualRoughness 0.08）的镜面球体，清晰反射周围天体。
  * **土星环带（Planetary Ring）**：环绕主行星的同心环状结构。
  * **几何卫星（Geometric Moon）**：具有周期自转与公转的次级天体。
  * **冰晶彗星（Ice Comet）**：大离心率椭圆轨道运行的半透明/高粗糙度冰晶天体。
* **DXR 1.1 光线追踪管线仿真**：
  * 实时构建与更新 TLAS（顶层加速结构）与 BLAS（底层加速结构）。
  * 模拟主光线（Primary Ray）、阴影光线（Shadow Ray）、反射光线（Reflection Ray）与环境光遮蔽（AO Ray）求交计算。
* **绚丽 3D 尾迹粒子流**：
  * 随空间天体公转动态生成发光微粒，具备生命周期衰减、色彩插值与空间漂移物理行为。
* **DX12 Ultimate 4 大支柱 HUD 实时看板**：
  * 实时采集 FPS、单帧耗时（ms）、已分配 GPU 显存预估。
  * 显示 DXR 1.1、Mesh Shader、VRS Tier 2、Sampler Feedback 4 大硬件特性的实时支持与激活状态。

### 1.3 交互控制快捷键

| 按键 | 功能 | 说明 |
|------|------|------|
| `Space` | 暂停 / 恢复天体公转与自转 | 方便定格观察特定光影与反射细节 |
| `H` | 隐藏 / 显示 HUD 看板 | 清爽全屏截图或观察完整画面 |
| `R` | 重新探测硬件 DX12U 特性 | 重新触发硬件支持度检查并打印遥测日志 |
| `P` | 动态倍增粒子发射速率 | 循环切换 1x -> 2x -> 4x -> 1x 密度 |
| `Esc` | 退出程序 | 优雅关闭窗口并释放资源 |

## 2. 2D 图形与引力粒子动力学演示 (`test_demo_2d`)

### 2.1 启动方式
```powershell
cargo run --example test_demo_2d
```

### 2.2 演示特性
* **2D 多层几何图元渲染**：中心发光核、公转多轨道几何行星与自转卫星。
* **引力动力学与微扰**：模拟天体轨道运动与引力牵引。
* **高频 2D 发光粒子系统**：连续发射发光粒子流，模拟离子尾流效果。
* **2D HUD 遥测信息**：实时展示当前帧率与粒子存活计数。

## 3. 核心子系统与 ECS 调度器验证演示 (`test_demo`)

### 3.1 启动方式
```powershell
cargo run --example test_demo
```

### 3.2 演示特性
* **纯无头模式 (Headless Mode)**：无需创建图形窗口，适合自动化 CI/CD 环境。
* **轨道力学数值积分求解**：验证 ECS 数据并行计算与系统链式调度（`.chain()`）。
* **自动化生命周期管理**：执行固定步长模拟并在验证完成后自动优雅退出，输出执行指标摘要。
