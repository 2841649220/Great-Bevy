# B0004

运行时警告。

一个带有层级继承（hierarchy-inherited）组件的 [`Entity`] 的 [`ChildOf`] 缺少所对应的层级继承组件。

Bevy 中定义的层级继承组件包括：

- [`InheritedVisibility`]
- [`GlobalTransform`]

第三方插件也可能定义自己的层级组件，因此请仔细阅读警告消息，注意缺失组件的具体类型。

要修复这个警告，请把缺失的层级组件添加到所有你想要使用该层级组件的实体的祖先上。

以下代码会触发警告：

```rust,no_run
use bevy::prelude::*;

// WARNING: this code is buggy
fn setup_cube(
    mut commands: Commands,
    mut meshes: ResMut<Assets<Mesh>>,
    mut materials: ResMut<Assets<StandardMaterial>>,
) {
    commands
        .spawn(Transform::default())
        .with_children(|parent| {
            // cube
            parent.spawn((
                Mesh3d(meshes.add(Cuboid::default())),
                MeshMaterial3d(materials.add(Color::srgb(0.8, 0.7, 0.6))),
                Transform::from_xyz(0.0, 0.5, 0.0),
            ));
        });

    // camera
    commands.spawn((
        Camera3d::default(),
        Transform::from_xyz(-2.0, 2.5, 5.0).looking_at(Vec3::ZERO, Vec3::Y),
     ));
}

fn main() {
    App::new()
        .add_plugins(DefaultPlugins)
        .add_systems(Startup, setup_cube)
        .run();
}
```

这段代码**不会**在屏幕上显示立方体。
这是因为用 `commands.spawn(…)` 生成的实体没有 [`ViewVisibility`] 或 [`InheritedVisibility`] 组件。
由于立方体是作为缺少可见性组件的实体的子实体生成的，它将完全不可见。

要修复这个问题，你还必须添加 [`Visibility`] 组件。
它会自动为你添加其他相关的可见性组件：

```rust,no_run
use bevy::prelude::*;

fn setup_cube(
    mut commands: Commands,
    mut meshes: ResMut<Assets<Mesh>>,
    mut materials: ResMut<Assets<StandardMaterial>>,
) {
    commands
        .spawn((Transform::default(), Visibility::default()))
        .with_children(|parent| {
            // cube
            parent.spawn((
                Mesh3d(meshes.add(Cuboid::default())),
                MeshMaterial3d(materials.add(Color::srgb(0.8, 0.7, 0.6))),
                Transform::from_xyz(0.0, 0.5, 0.0),
            ));
        });

    // camera
    commands.spawn((
        Camera3d::default(),
        Transform::from_xyz(-2.0, 2.5, 5.0).looking_at(Vec3::ZERO, Vec3::Y),
     ));
}

fn main() {
    App::new()
        .add_plugins(DefaultPlugins)
        .add_systems(Startup, setup_cube)
        .run();
}
```

当 [`GlobalTransform`] 组件缺失时也会出现类似的问题。
不过，由于它是 `Transform` 的必需组件，每当插入 `Transform` 时，它都会被自动插入。

当你把一个场景（Scene）加载为某个预先存在、但缺少相应组件的 [`Entity`] 的子级时，你很可能会遇到这个警告。
