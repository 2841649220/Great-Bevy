# B0002

为了在资源上遵守 [Rust 的引用规则](https://doc.rust-lang.org/book/ch04-02-references-and-borrowing.html#the-rules-of-references)（要么是一个可变引用，要么是任意数量的不可变引用），在同一个系统中，同一类资源不能出现多个，否则就会出现冲突。这可能发生在同一个 `T` 的 [`Res<T>`](https://docs.rs/bevy/*/bevy/ecs/system/struct.Res.html) 和 [`ResMut<T>`](https://docs.rs/bevy/*/bevy/ecs/system/struct.ResMut.html) 之间，或者同一个 `T` 的 [`NonSend<T>`](https://docs.rs/bevy/*/bevy/ecs/system/struct.NonSend.html) 和 [`NonSendMut<T>`](https://docs.rs/bevy/*/bevy/ecs/system/struct.NonSendMut.html) 之间。

错误代码示例：

```rust,should_panic
use bevy::prelude::*;

fn update_materials(
    mut material_updater: ResMut<Assets<StandardMaterial>>,
    current_materials: Res<Assets<StandardMaterial>>,
) {
    // ...
}

fn main() {
    App::new()
        .add_plugins(DefaultPlugins)
        .add_systems(Update, update_materials)
        .run();
}
```

这段代码会触发 panic，因为不可能同时对 `Assets<StandardMaterial>` 进行可变和不可变的资源访问。

由于可变资源本身就能访问到当前资源的值，你可以移除不可变资源。

```rust,no_run
use bevy::prelude::*;

fn update_materials(
    mut material_updater: ResMut<Assets<StandardMaterial>>,
) {
    // ...
}

fn main() {
    App::new()
        .add_plugins(DefaultPlugins)
        .add_systems(Update, update_materials)
        .run();
}
```

## 资源即组件

在底层实现中，资源*就是*组件。这通常只是一个实现细节，不会有其他影响，但你可能会遇到下面的系统抛出错误的情况：

```rust,no_run
# use bevy::prelude::*;
# #[derive(Resource)]
# struct MyResource;
fn system(all_entities: Query<EntityMut>, res: Res<MyResource>) {}
```

当资源存储在实体上时，不可能同时查询所有实体和一个资源。
要解决这个问题，你应该要么约束 `all_entities` 查询（你通常不需要查询*每一个*实体），要么使用 `Without<MyResource>` 或 `Without<IsResource>` 来排除 `MyResource`。
这里的 `IsResource` 是每一个持有资源的实体上的标记组件，如果你想排除资源，用它非常方便。

可能与 `Res` 或 `ResMut` 冲突的查询包括：

- `Query<()>`
- `Query<Entity>`
- `Query<EntityMut>`
- `Query<EntityRef>`
- `Query<EntityMutExcept>`
- `Query<EntityRefExcept>`
- `Query<Option<&T>>`

非发送（non-send）数据也会遇到同样的问题：

```rust,no_run
# use bevy::prelude::*;
# #[derive(Resource)]
# struct MyNonSend;
fn system(all_entities: Query<EntityMut>, some_non_send: NonSend<MyNonSend>) {}
```

这可以通过在查询中添加 `Without<MyNonSend>` 过滤器来解决。
