# B0001

为了在组件上遵守 [Rust 的引用规则](https://doc.rust-lang.org/book/ch04-02-references-and-borrowing.html#the-rules-of-references)（要么是一个可变引用，要么是任意数量的不可变引用），在同一个系统中，同一个组件上不能有两个查询（Query），并且其中一个对组件请求可变访问。

错误代码示例：

```rust,should_panic
use bevy::prelude::*;

#[derive(Component)]
struct Player;

#[derive(Component)]
struct Enemy;

fn move_enemies_to_player(
    mut enemies: Query<&mut Transform, With<Enemy>>,
    player: Query<&Transform, With<Player>>,
) {
    // ...
}

fn main() {
    App::new()
        .add_plugins(DefaultPlugins)
        .add_systems(Update, move_enemies_to_player)
        .run();
}
```

这段代码会触发 panic，因为不可能同时对 `Transform` 进行可变和不可变的查询。

你有两种解决方案：

解决方案 #1：使用 [`Without`](https://docs.rs/bevy/*/bevy/ecs/query/struct.Without.html) 实现互不重叠的查询

由于一个 `Player` 实体不会同时是 `Enemy`，这两个查询实际上永远不会指向同一个实体。这可以通过 [`Without`](https://docs.rs/bevy/*/bevy/ecs/query/struct.Without.html) 在查询过滤器中表达出来：

```rust,no_run
use bevy::prelude::*;

#[derive(Component)]
struct Player;

#[derive(Component)]
struct Enemy;

fn move_enemies_to_player(
    mut enemies: Query<&mut Transform, With<Enemy>>,
    player: Query<&Transform, (With<Player>, Without<Enemy>)>,
) {
    // ...
}

fn main() {
    App::new()
        .add_plugins(DefaultPlugins)
        .add_systems(Update, move_enemies_to_player)
        .run();
}
```

解决方案 #2：使用 `ParamSet`

`ParamSet` 允许你把互相冲突的查询作为参数传入，但你仍然需要负责在系统中避免同时使用它们。

```rust,no_run
use bevy::prelude::*;

#[derive(Component)]
struct Player;

#[derive(Component)]
struct Enemy;

fn move_enemies_to_player(
    mut transforms: ParamSet<(
        Query<&mut Transform, With<Enemy>>,
        Query<&Transform, With<Player>>,
    )>,
) {
    // ...
}

fn main() {
    App::new()
        .add_plugins(DefaultPlugins)
        .add_systems(Update, move_enemies_to_player)
        .run();
}
```

## 注意

如果在使用资源（Resource）时遇到这个错误，请查看 [B0001](https://bevy.org/learn/errors/b0002) 获取更多信息。
